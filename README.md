# Ankit Agrawal Portfolio

Live URL: https://ankitagr09.github.io/

A static multi-page portfolio website focused on performance, SEO, CRO, and LLM discoverability.

## Pages
- `index.html` - Home
- `about.html` - About
- `services.html` - Services
- `projects.html` - Projects
- `contact.html` - Contact

## Tech Stack
- HTML5
- CSS3 (`css/styles.css`)
- Vanilla JavaScript (`js/scripts.js`)
- Three.js (CDN)

## SEO and Discoverability Setup
- Absolute canonical URLs on all pages
- Open Graph + Twitter meta tags
- Structured data (JSON-LD)
- `robots.txt`
- `sitemap.xml`
- `llms.txt` for LLM-friendly site context
- `favicon.svg` and `site.webmanifest`
- Social preview image: `og-image.svg`

## Local Development
This is a static website. You can run it with any local static server.

Example (VS Code Live Server):
1. Open folder in VS Code
2. Start Live Server on `index.html`

Or Python:
```bash
python -m http.server 5500
```
Then open `http://localhost:5500`.

## Deployment (GitHub Pages)
The site is deployed at:
- https://ankitagr09.github.io/

To update deployment:
1. Commit and push changes to the configured GitHub Pages branch.
2. Wait for GitHub Pages to rebuild.
3. Validate:
   - https://ankitagr09.github.io/
